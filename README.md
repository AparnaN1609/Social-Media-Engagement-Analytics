📱 Social Media Engagement Analytics Using Python

📌Project Overview

This project focuses on analyzing social media engagement data using Python. The main objective is to understand audience behaviour, identify content performance trends and generate meaningful insights from social media metrics.
The dataset contains 5,000 records and 19 columns, including likes, comments, shares, impressions, watch time, engagement rate, post type, content category, country and sentiment.

🔍 Key Findings and Interpretations

Post Type: Video posts recorded the highest average engagement score, indicating greater user interaction compared to other post types.

Content Category: Music was the best-performing content category based on average engagement score, while fashion recorded the lowest.

Country-wise Engagement: Australia recorded the highest average engagement rate, whereas India recorded the lowest.

Age Group: Users aged 30–40 recorded the highest average engagement score, indicating greater interaction within this age group.

Verified Accounts: Non-verified accounts recorded a slightly higher average engagement score than verified accounts, suggesting that verification status alone does not guarantee higher engagement.

Device Type: Mobile users recorded the highest average watch time compared to tablet and desktop users.

Sentiment Analysis: Negative sentiment posts achieved the highest average engagement score, while neutral sentiment posts recorded the lowest.

Correlation Analysis: Likes and engagement score showed a strong positive correlation (0.984), while impressions and engagement rate showed a strong negative correlation (-0.781).


🎯 Conclusion

The analysis highlights different patterns in social media engagement based on post type, content category, country, age group, account verification status, device type and sentiment. Video posts and music-related content performed better in terms of average engagement score. Australia recorded the highest average engagement rate, while mobile users showed the highest watch time.
This project demonstrates the application of Python libraries for data cleaning, exploratory data analysis, statistical analysis and visualization to generate meaningful insights from social media data.
